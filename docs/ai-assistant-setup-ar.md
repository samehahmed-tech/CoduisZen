# إعداد RestoFlow Copilot

## المزود المجاني

- `SYSTEM`: مساعد داخلي مجاني بدون مفتاح، يلخص البيانات المتاحة ويجهز الإجراءات للمراجعة.
- `OLLAMA`: تشغيل نموذج محلي بدون إرسال بيانات لمزود خارجي، عند تفعيل Ollama على السيرفر.
- يمكن استخدام مفاتيح free-tier من Gemini أو مزود آخر حسب الحصة المتاحة.

## إعداد Gemini أو NVIDIA

1. افتح الإعدادات → المساعد الذكي.
2. اختر `Google Gemini` أو `NVIDIA NIM`.
3. اختر Server Key إذا أُضيف المفتاح في بيئة السيرفر، أو Custom Key لإدخاله وتخزينه مشفرًا.
4. اكتب Model ID.
5. اختر مزودين بدلاء.
6. احفظ الإعدادات.

إذا فشل النموذج بسبب timeout أو overload أو quota، يجرب النظام المزودين البدلاء بحد أقصى مرة لكل مزود، ثم يعود إلى System Copilot عند فشل الجميع.

## OpenAI-compatible

يجب ضبط `AI_ALLOWED_PROVIDER_HOSTS` في بيئة السيرفر بقائمة hostnames مفصولة بفواصل، مثل:

```env
AI_ALLOWED_PROVIDER_HOSTS=api.example.com,api.internal.example
```

لا يتم قبول HTTP لمزود خارجي، ولا يتم السماح بمضيف غير موجود في القائمة. `localhost` وOllama المحلي لهما مسار منفصل.

## الصلاحيات والبيانات

- التحليل يلتزم بالفرع الفعال وصلاحيات المستخدم.
- الأرقام تأتي مع نطاق وفرع ووقت تحديث.
- الطلبات التي تغير بيانات لا تنفذ مباشرة: Preview ثم تأكيد ثم Audit.
- مفاتيح API لا تظهر في المتصفح ولا في سجل المحادثة.
