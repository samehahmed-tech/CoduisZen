RestoFlow Catalog Data Update

1) ضع ملف RestoFlow-Catalog-Import-*.sql داخل هذا المجلد.
2) اضغط كليك يمين على Apply Catalog Update.bat ثم Run as administrator.
3) اكتب IMPORT عند الطلب.
4) انتظر SUCCESS.

الأداة لا تعيد تثبيت النظام.
تأخذ Backup متحققاً منه قبل التحديث.
تضيف أقسام المنيو، الأصناف، الإضافات، الأصناف المخزنية، والريسبي.
أي خطأ يلغي كل تغييرات ملف SQL.
