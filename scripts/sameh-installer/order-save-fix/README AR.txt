RestoFlow Order Save Fix 1.1.10

1) فك ضغط ZIP بالكامل.
2) شغل Fix Order Save.bat.
3) وافق Yes على رسالة UAC.
4) انتظر SUCCESS.
5) افتح النظام واضغط Ctrl+F5 ثم جرّب حفظ Order.
6) افتح اختصار RestoFlow KDS Lite الجديد من Desktop.

الإصلاح يمنع تشغيل استعلامين متوازيين داخل نفس SQL Server transaction.
الأداة تأخذ Backup متحققاً منه، وتحفظ server القديم للـRollback، ثم تفحص صحة النظام.
الأداة تحدث kdslite.html وتسمح لشاشات KDS داخل نفس شبكة المطعم بالعمل بدون Screen Key.
افتح من Android: http://192.168.1.100:3001/kdslite.html
إذا فشل التحديث يرجع server القديم تلقائياً.
