RestoFlow Final Session, Menu, Printer and Inventory Fix 1.1.8

طريقة الاستخدام:
1) فك ضغط الملف بالكامل في مجلد واحد.
2) اضغط كليك يمين على Fix Installed System.bat واختر Run as administrator.
3) انتظر رسالة SUCCESS. السكربت يعيد تشغيل النظام والبريدج ويفحصهما تلقائيًا.
4) افتح http://127.0.0.1:3001 ثم اعمل Ctrl+F5 وسجل الدخول من جديد.

إصلاحات 1.1.8:
- إصلاح انتهاء جلسة التجديد مع الـAccess Token، وهو سبب تسجيل الخروج التلقائي و401 في الطابعات وPrint Gateway.
- منع تكرار logout وطلبات 401 عند فشل عدة طلبات في نفس اللحظة.
- إصلاح CORS بين صفحة النظام على localhost:3001 والبريدج على 3002.
- إصلاح 500 عند تعديل صنف المنيو مع السعر والريسبي وحقول الواجهة الإضافية.
- دعم حالة أرشفة صنف المنيو بدون فشل Validation.
- إضافة الكمية الحالية لكل مخزن داخل شاشة إضافة وتعديل صنف المخزون، مع تسجيلها كحركة تسوية حقيقية.
- إنشاء مستخدم كاشير احتياطي PIN 111111، بجانب مستخدم الإدارة الاحتياطي PIN 202626.
- إضافة 3 قوالب إيصال 80mm: كلاسيك كامل، مختصر سريع، وهوية بارزة، مع اسم المطعم واللوجو وQR.
- تثبيت إعدادات Tasks لتعمل بدون نوافذ ظاهرة وعلى الكهرباء أو البطارية.
- تسريع التقاط أوامر الطباعة إلى نصف ثانية، وتحويل صور طابعة الشبكة مباشرة داخل Node بدون PowerShell أو ملف PNG مؤقت.
- إزالة انتظار حركة الانتقال بين الصفحات، وتحسين التحميل المسبق باللمس، وجعل شاشة إضافة صنف المخزون مناسبة للشاشات الصغيرة.
- إصلاح Setup للعميل الجديد: حسابا الإنقاذ لا يمنعان إنشاء المالك الحقيقي من /setup.
- إصلاح Upgrade فوق نسخة قديمة: حذف Tasks القديمة وإيقاف عمليات RestoFlow اليتيمة قبل استبدال الملفات.
- يشمل إصلاح SQL Date Parameters السابق، والطباعة العربية 80mm، والإجمالي والقطع التلقائي، وحفظ إعدادات الطابعات، وطابعة الكاشير الأساسية، واستيراد Excel للمخزون.

ما يفعله السكربت تلقائيًا:
- يأخذ نسخة احتياطية مؤكدة من قاعدة البيانات والملفات.
- يوقف Tasks وعمليات النظام والبريدج مؤقتًا.
- يثبت ملفات الواجهة والسيرفر والبريدج الجديدة.
- يضبط POLL_MS=500 تلقائيًا للبريدج.
- يعيد تشغيل النظام ويفحص اتصال قاعدة البيانات.
- يختبر Admin PIN 202626 وCashier PIN 111111، وتجديد الجلسة، وAPI الطابعات، وCORS/Health للبريدج.
- عند أي فشل يعيد الملفات القديمة تلقائيًا.

ملاحظة USB:
ثبت تعريف الطابعة في Windows وتأكد أنها تطبع Windows Test Page. بعد ذلك اختر USB على الجهاز، اختر اسم الطابعة المكتشفة، واجعلها Primary Cashier ثم اطبع Test Receipt.

لا تحذف مجلد payload، ولا تشغل ملف PowerShell منفردًا من مكان آخر.
