RestoFlow PostgreSQL Catalog Export

شغّل Export PostgreSQL Catalog SQL.bat على جهاز يستطيع الاتصال بقاعدة PostgreSQL القديمة.
اكتب بيانات الاتصال وكلمة المرور.
الناتج ملف RestoFlow-Catalog-Import-<date>.sql داخل نفس المجلد.
انقل ملف SQL فقط إلى جهاز العميل.

الأداة تقرأ قاعدة PostgreSQL ولا تعدلها.
ملف SQL لا يحتوي كلمة المرور أو بيانات الاتصال.
