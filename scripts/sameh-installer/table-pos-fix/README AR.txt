RestoFlow - التحديث النهائي والإصلاح السريع 1.1.22

التشغيل:
1) فك ضغط الملف بالكامل.
2) كليك يمين على Apply Table POS Fix.bat ثم Run as administrator.
3) انتظر رسالة SUCCESS.

الإصلاح يقوم تلقائياً بـ:
- Backup كامل لقاعدة البيانات مع التحقق منها قبل أي تعديل.
- إرجاع كل الطاولات إلى AVAILABLE ومسح ربط الطلب والقفل المعلق.
- تثبيت الإصلاح الدائم للطاولات وإغلاق اليوم.
- تبسيط طلبات الصالة: إرسال للمطبخ ثم إغلاق وطباعة من شاشة الطاولات.
- إضافة Reset إداري للطاولة وإصلاح الكاش والطلبات المعلقة.
- إضافة اعتماد خصم البرومو بـ PIN مدير مخفي.
- تثبيت طرق الدفع المخصصة وإظهارها في شاشة الكاشير.
- تثبيت قوالب الإيصال الافتراضية العامة وحسب الصالة/التيك أواي/الدليفري/الاستلام/الكشك.
- تحسين محاذاة الشيك وإظهار اللوجو وQR بدون تغيير مقاسات الطباعة.
- تحديث الكشك والثيمات والتقارير وتفاصيل الإلغاء والمرتجعات.
- ربط باتشات الإنتاج بوصفات قاعدة البيانات والمخزون مع دعم BOM كبديل.
- حفظ نسخة Rollback من ملفات البرنامج القديمة.

لا تغلق النافذة أثناء التنفيذ. عند الفشل ترجع ملفات البرنامج القديمة تلقائياً، وتظل نسخة قاعدة البيانات موجودة داخل مجلد backups.
