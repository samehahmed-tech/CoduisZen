# دليل استخدام الموارد البشرية والرواتب

هذه نسخة مختصرة من دليل الموارد البشرية داخل النظام.

## أسرع مسار تشغيل

1. اختار الفرع الصحيح.
2. جهز الإدارات والأقسام والمسميات.
3. أضف الموظفين وحدد الفرع والقسم والمسمى والراتب وكود البصمة.
4. أضف مستندات الموظف كرابط Google Drive أو ملف.
5. راجع أجهزة البصمة وحالة الاتصال.
6. أنشئ قوالب الورديات وخطة الأسبوع.
7. اسحب البصمات وراجع الاستثناءات.
8. أنشئ دورة رواتب واضغط احتساب.
9. راجع blockers والتحذيرات.
10. صدر شيت الرواتب ثم أغلق واعتمد الدورة.

## أهم الأسئلة

س: الموظف غير ظاهر؟
ج: راجع الفرع وحالة الموظف.

س: البصمة غير مربوطة؟
ج: أضف كود البصمة في ملف الموظف.

س: الراتب صفر؟
ج: راجع الراتب الأساسي وأجر الساعة ودورة الرواتب.

س: لا يمكن الإغلاق؟
ج: عالج blockers ثم أعد الاحتساب.

س: السلفة لا تخصم؟
ج: تأكد أنها معتمدة أو مصروفة وأن القسط داخل فترة الدورة.
